Slice of How

Everything has a hidden inside. We slice it open.

Short English videos that cut famous structures, machines and everyday objects open in 3D to show how they really work: the parts you pass every day and never see.

Visit the channel @sliceofhow

What we make

Each video takes one thing people see but never think about, opens with its most surprising number, names what most people assume, and then cuts it open to show what is really going on. Concrete measurements, real names and dates, no hype.

  • What's insideEveryday things cut in half, like how a gas pump knows when to stop.
  • What's underneathThe hidden layers below streets, stations and landmarks.
  • How it was builtHow engineers beat water, height, weather and bad ground.

Narration uses a synthetic voice. Visuals are mostly 3D illustrations; some videos also include data charts, licensed stock footage or photos, and AI-generated scenes. Read how our videos are made.

About our tools

Videos on this channel are produced and uploaded only by the channel owner, using a private tool called Slice of How Uploader. It is a command-line program that runs on the owner's own computer. It has one user, works only with the Slice of How channel, and is not distributed, sold or offered to anyone else.

Slice of How Uploader uses YouTube API Services.

With the permission the owner grants through Google sign-in, it uses the YouTube Data API and the YouTube Analytics API to:

  • upload this channel's videos and schedule when they go public;
  • add new videos to the channel's playlists and set the channel's description, keywords, banner and watermark;
  • read this channel's own analytics to see which videos viewers watch longest.

Use of the tool is subject to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy, and access can be removed at any time on Google's permissions page.

Data the tool reads from YouTube is stored only on the owner's computer. The one exception is a short summary of aggregated performance numbers for the channel's own videos, which is sent to the Anthropic Claude API to help choose future topics. It contains nothing about viewers. Our Privacy Policy explains exactly what the tool reads, stores and shares, and how that data is deleted.

1. Who we are

Slice of How (@sliceofhow) is a channel of short English videos that explain hidden engineering with 3D cutaway animations. It is run by one individual creator based in South Korea, called “we”, “us” or “the owner” in this policy. You can reach us at the address in section 13.

2. Scope

This policy covers two things:

  • Slice of How Uploader (“the tool”), a private command-line program the owner wrote and runs on the owner's own Windows PC to produce the channel's videos and publish them. It has exactly one user, the owner. It is not distributed, sold or offered to anyone else, it has no web server and no user accounts, and it works only with the Slice of How channel.
  • This website, sliceofhow.github.io.

When you watch our videos on YouTube, YouTube's own privacy practices apply. The tool never receives information that identifies individual viewers.

3. YouTube API Services

Slice of How Uploader uses YouTube API Services: the YouTube Data API v3 and the YouTube Analytics API. By using the tool, its user agrees to be bound by the YouTube Terms of Service.

The owner authorizes the tool through Google OAuth 2.0 (the desktop-app flow) in the system browser. The tool never sees the Google password. It requests these permissions, all used only for the owner's own channel:

Permission (scope)Used for
youtube.uploadUploading the owner's videos.
youtubeSetting the channel's description, keywords, country, language, banner and watermark; creating playlists and adding videos to them.
youtube.readonlyReading channel, video and playlist details. This overlaps with the youtube permission.
yt-analytics.readonlyReading YouTube Analytics reports for the owner's channel.
yt-analytics-monetary.readonlyReading estimated revenue for the owner's videos once it is available. Until then the tool leaves revenue out.

The tool does not request the Google account's email address or profile, or access to any other Google service.

4.2 What the tool changes on the channel

  • Uploads the owner's own videos with a title, description (with source and credit lines and hashtags), tags, category and language. Videos are normally uploaded as private with a scheduled publish time, marked as not made for kids, and marked with YouTube's altered or synthetic content disclosure when they contain AI-generated images or clips.
  • Test upload: one 6-second unlisted test clip, uploaded without notifying subscribers, to check that uploads publish normally. The owner deletes it in YouTube Studio.
  • Branding: sets the channel description, keywords, default language and country, uploads the banner image and sets the video watermark.
  • Playlists: creates public series playlists and adds each new video to one.

The tool does not delete or edit existing videos, post or read comments, or manage subscriptions.

4.3 The tool's own calculations

The tool calculates the following itself from the stored numbers. They are calculated by Slice of How Uploader, not by YouTube, and are not YouTube metrics. They appear only in the owner's private daily report, in the topic-suggestion request described in section 6.2 and in the tool's local choice of the next video format. They are never published on the channel or anywhere else.

  • A ranking score: 0.5 × z(average percentage viewed) + 0.3 × z(log of engaged views) + 0.2 × z(subscribers gained), for the channel's own Shorts that are at least 72 hours old and from the last 90 days. A z-value compares a video with the average of the channel's own videos.
  • Per-format averages of these numbers.
  • The share of views from the US, UK, Canada and Australia over the last 28 days.
  • Progress toward the YouTube Partner Program thresholds.

YouTube's numbers are stored as YouTube reports them; these calculations never overwrite them.

5. What is stored and where

Everything is stored on the owner's PC, in a private data folder in the owner's Windows user account, outside any cloud-synced folder and outside source control. Nothing is stored on a server.

The same folder also holds files with no YouTube data: the tool's own OAuth app credentials, video work folders and manual upload packages. The setup commands print the channel title, ID and subscriber count in the owner's terminal to confirm the sign-in; that output is not saved.

All API calls use HTTPS. The data folder is never shared, committed to source control or placed in cloud storage.

6. What is shared

6.1 Google and YouTube

The uploads and channel changes in section 4.2 are sent to YouTube through YouTube API Services.

6.2 Anthropic (Claude API)

When the tool proposes the next video topic on its own, it asks Anthropic's Claude API for ideas (up to 3 requests per new video, normally 2 videos a day). Once at least one of the channel's own Shorts is more than 72 hours old and has been measured, the request includes a short performance summary built from the stored metrics. That summary contains only:

  • the number of measured Shorts, the age and time-window rules, and the formula of the tool's own ranking score (section 4.3; calculated by Slice of How Uploader, not a YouTube metric);
  • for up to 5 of the best-scoring and up to 5 of the worst-scoring Shorts by that score: the tool's own topic, format and angle text, the average percentage viewed (rounded), engaged views in short form such as “1.2K” (views when engaged views are unavailable) and subscribers gained;
  • for each video format: the number of videos, the average percentage viewed, the average engaged views and the average of the tool's own ranking score (calculated by Slice of How Uploader, not a YouTube metric).

It does not include video IDs, video titles, the channel ID or name, subscriber totals, likes, comments, shares, view duration, revenue, country data, the sign-in token or anything about viewers. No summary is included when the owner chooses the topic. The summary is added automatically; the tool has no setting to turn it off. Its purpose is to steer new topics toward what viewers watch longest. Anthropic handles these requests under its own privacy policy.

The tool also gives formats with a higher average ranking score more weight when it picks the next format. That happens on the owner's PC; nothing is sent.

6.3 Other services used to make videos

The tool also uses Anthropic's Claude API (research, scripts and review), SEC EDGAR and FRED (public data), Pexels and Pixabay (stock footage and photo search), and, when enabled, Higgsfield and OpenAI (AI images and clips) and ElevenLabs (voice). They receive only the tool's own topics, prompts, scripts and search terms. None of them receives YouTube API data or the Google sign-in token.

6.4 Nothing else

No data is sold, rented or given to advertisers or data brokers. No third party serves content or ads through the tool, and no one other than the owner can see the data it stores.

7. Retention and deletion

7.1 How long data is kept

The tool never deletes YouTube data automatically. Each item in section 5 is kept until it is deleted by hand:

  • Sign-in token: kept while the tool is in use, and rewritten whenever it is renewed or the owner signs in again.
  • Video records: one row per video, kept until deleted.
  • Performance history: each daily run (or on-demand report) adds a new row for every public video published in the last 60 days. Private and scheduled videos are skipped. Older videos are no longer checked, but their rows remain.
  • Reports, logs and state files: one report and one log per day, kept until deleted.

Video work folders, which hold only the owner's own content, are deleted automatically after 30 days. If access is revoked or the token expires, the tool's API calls fail and it asks the owner to sign in again; stored data is not changed.

7.2 How data is deleted

The tool has no built-in delete or revoke command, so deletion is done by hand, by removing these items from the data folder:

  • the sign-in token;
  • the local database (or only its performance-history table);
  • the reports and logs;
  • the state files.

To request deletion, email the address in section 13. We delete the stored data within 7 days of a request, and within 7 days after access is revoked. Deleting local data does not remove anything from YouTube; videos, playlists and channel settings stay on the channel and are managed in YouTube Studio.

8. How to revoke access

  1. Open Google's permissions page: https://security.google.com/settings/security/permissions (Google Account > Security > Third-party connections).
  2. Select Slice of How Uploader.
  3. Remove its access.

After that, the stored token stops working and the tool can no longer read or change the channel. To remove the stored data as well, see section 7.2.
